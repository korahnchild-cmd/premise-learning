관리자 전용 페이지입니다

운영자 계정으로 로그인해야 열람할 수 있습니다.
이 페이지의 기능은 본인 브라우저의 표시 상태만 바꾸며, 서버의 구독 권한은 변경하지 않습니다.

홈으로

이미 다른 계정으로 로그인돼 있으면 먼저 로그아웃해야 합니다. 위 버튼이 로그아웃까지 함께 처리합니다.

왜 막혔는지 확인

"이메일 없음"으로 나오면 카카오·네이버 계정입니다. 이 계정을 관리자로 쓰려면 위 Firebase UID를 복사해 common.js의 ADMIN_UIDS 배열에 넣으세요. 구글 계정으로 쓰실 거면 "다른 계정으로 로그인"을 누르시면 됩니다.

관리자 테스트 콘솔

회원 상태와 학습 데이터를 바꿔가며 화면을 확인합니다. 이 브라우저의 로컬 상태만 바뀝니다.

확인 중

1 · 회원 상태

게이팅·CTA·배너가 상태별로 어떻게 바뀌는지 확인합니다.

2 · 학습 데이터 시나리오

파트너 노트·리포트·마인드맵이 기간별로 무엇을 보여주는지 확인합니다. 가짜 이력이 노출되는지 잡아내는 용도입니다.

* 시나리오를 적용하면 기존 학습 기록이 덮어써집니다. 본인 실제 기록이 있는 계정에서는 주의하세요.

3 · 베타 테스터 플랜 부여

서버 반영 · 실제 권한

위 1·2번은 이 브라우저만 바뀌지만, 여기서 부여한 플랜은 해당 계정에 실제로 적용됩니다. 결제수단 없이 접근만 열리고 자동청구는 발생하지 않습니다.
